1. PROJECT OVERVIEW & CORE OBJECTIVES
====================================================================================================
The Real-Time Crime and Weapon Detection System (Fast-Track AI) is an autonomous, high-throughput,
multi-modal neural surveillance platform designed to detect armed threats and physical violence in
real-time across enterprise CCTV networks, RTSP IP cameras, webcams, and pre-recorded forensic footage.

Core Capabilities:
1. Real-Time Weapon Detection: Fine-tuned Ultralytics YOLO11n model identifying handguns, knives,
   and assault weapons with high temporal precision.
2. 2D Discrete Wavelet Transform (DWT) Preprocessing: Enhances subtle high-frequency edge gradients
   (weapon contours, metallic reflections) in poor CCTV lighting conditions prior to inference.
3. False-Alarm Suppression Subsystem: Smartphone geometric filtering and bounding-box suppression
   to eliminate false gun flags caused by mobile phones, wallets, or handheld tools.
4. Spatiotemporal Violence / Fight Detection: Action recognition using MobileNetV2-LSTM and R3D-18
   3D CNNs to evaluate temporal motion dynamics and human-to-human physical combat.
5. Automated Forensic Incident Locking: In-memory pre-roll and post-roll video ring buffers that
   cut raw and annotated MP4 evidence clips with SHA-256 tamper-evident digital hashes.
6. Unified Operator Interfaces:
   - Modern Next.js 14 Web Application for real-time video monitoring, incident review, and triage.
   - Streamlit Command Center for model benchmarking, ROC/PR curve analytics, and audit log exports.
   - FastAPI High-Performance REST API backend coordinating inference, database, and telemetry.

3. SYSTEM ARCHITECTURE & DATA FLOW
====================================================================================================
[Camera Ingestion] ---> [In-Memory Ring Buffer] ---> [Wavelet / Preprocessing]
       |                                                      |
(RTSP / Webcam / File)                                        v
                                                +----------------------------+
                                                |   Dual Neural Pipelines    |
                                                +----------------------------+
                                                | 1. YOLO11n Weapon Head     |
                                                |    - Phone Suppression     |
                                                |    - Geometric Verifier    |
                                                | 2. MobileNet-LSTM / R3D-18 |
                                                |    - Spatiotemporal Action |
                                                |    - Kinetic Dynamics      |
                                                +----------------------------+
                                                              |
                                                              v
                                                [Event Engine & Severity Triage]
                                                              |
                              +-------------------------------+-------------------------------+
                              |                               |                               |
                              v                               v                               v
                    [SQLite WAL Database]          [Evidence Clip Cutter]            [Real-time Dispatches]
                    (Incidents, Audit Logs)       (Raw MP4 + SHA-256 Hash)          (Next.js UI & Webhooks)

Detailed Flow Breakdown:
1. Video Ingestion:
   - Supported inputs: Live USB webcams (`/dev/video0` or `0`), RTSP IP camera streams (`rtsp://`),
     and pre-recorded MP4/AVI security clips.
   - Robust reconnection manager handles RTSP dropouts with exponential backoff and watchdog restarts.

2. Wavelet Edge Enhancement:
   - Employs 2D Discrete Wavelet Transform (DWT) using Haar wavelets to separate input frames into
     approximation (LL) and high-frequency subbands (LH, HL, HH).
   - High-frequency subbands are amplified and re-synthesized via Inverse DWT (IDWT) to enhance blade
     edges, barrel outlines, and metallic specular highlights before YOLO inference.

3. Weapon Detection & Smartphone Rejection:
   - YOLO11n detects weapons (`gun`, `knife`).
   - Phone Suppression Filter: Simultaneously evaluates COCO class 67 (`cell phone`). If a detected
     box heavily overlaps with a cell phone bounding box (IoU > 0.40) or matches smartphone geometric
     characteristics (aspect ratio > 1.65 with uniform flat texture), it is filtered out to prevent
     embarrassing false alarms.
   - Spatial Pose Prior: Rejects weapon false positives located at ground level near shoes/floors.

4. Spatiotemporal Violence Classification:
   - Samples 16-frame temporal sliding windows.
   - Passes frames through MobileNetV2 feature extractor linked to an LSTM temporal head (or R3D-18).
   - Multi-person kinetic contact gating ensures violent alerts trigger only when human interaction
     is detected, suppressing false alarms from isolated fast movements.

5. Event Engine & Severity Calculation:
   - Combines peak weapon confidence ($W$) and peak violence score ($V$) into a composite score:
     $Threat = \max(W, V) \times 0.7 + \min(W, V) \times 0.3$.
   - Applies dual-threshold hysteresis (trigger threshold: 0.70, release threshold: 0.45) to prevent
     alert flickering.
   - Severity categorized as Critical, High, Medium, Low, or Safe.

6. Evidence Preservation & Chain of Custody:
   - Pulls 5 seconds pre-roll and 5 seconds post-roll frames from the in-memory ring buffer.
   - Asynchronously encodes raw MP4 and annotated MP4 clips using FFmpeg / OpenCV H.264.
   - Computes SHA-256 cryptographic digest of the file and stores it in the immutable audit log.

5. REST API ENDPOINTS SPECIFICATION (FASTAPI)
====================================================================================================
Base URL: http://127.0.0.1:8000

1. `POST /api/detect`
   - Description: Accepts a video frame (JPEG base64 or multipart image) and returns neural detections.
   - Pipeline: Applies Wavelet enhancement -> YOLO11n weapon detector -> Phone suppression ->
     Violence classifier -> Returns bounding boxes, labels, confidence scores, and threat status.
   - Auto-Incident Trigger: When a high-confidence threat (>0.70) is detected, an incident is
     automatically persisted into SQLite, snapshot saved to disk, and alert broadcast.

2. `GET /api/incidents`
   - Description: Retrieves paginated list of recorded incidents.
   - Query Parameters: `limit` (default: 50), `severity` (optional filter: critical, high, medium, low).

3. `POST /api/incidents`
   - Description: Manually records or auto-generates a new security incident.
   - Payload: `camera_id`, `severity`, `threat_type`, `description`, `confidence`.

4. `POST /api/incidents/{incident_id}/status`
   - Description: Updates the forensic status of an incident (used by triage buttons).
   - Payload: `{"status": "in_review" | "resolved" | "escalated", "reviewer_notes": string}`
   - Action: Updates SQLite record, writes an immutable record to the audit log with timestamp.

5. `GET /api/cameras` & `POST /api/cameras`
   - Description: Lists all monitored cameras and registers new RTSP or webcam sources.

6. `GET /api/stream/{clip_name}`
   - Description: High-speed video streaming endpoint supporting HTTP 206 Partial Content range
     headers for seamless scrubbing and replay in web browsers.

7. `GET /health`
   - Description: System heartbeat returning GPU VRAM availability, active camera count, and uptime.

6. FORENSIC INCIDENT TRIAGE WORKFLOW
====================================================================================================
When an incident is detected or opened in the Next.js Drawer or Streamlit Reviewer:
1. "Confirm Threat" Button:
   - Action: Transitions status to `in_review`.
   - Result: Confirms human operator validation of the AI detection. Generates an immediate audit
     log entry: "Status changed to in_review. Threat confirmed by Operator."

2. "False Alarm" Button:
   - Action: Transitions status to `resolved` with resolution tag `false_alarm`.
   - Result: Automatically cancels active audible sirens, resets threat hysteresis, and updates
     analytics metrics to recalculate False Alarm Rate (FAR).

3. "Escalate" Button:
   - Action: Transitions status to `escalated`.
   - Result: Elevates priority to Maximum Criticality, triggers high-priority security webhooks,
     and locks all recorded MP4 video segments against retention purge policies.
